# September 30 audit regressions in the Rust port

This page tracks the technical regression families from the previous audit.
Historical Python execution evidence is not qualification of the native rewrite;
consult the latest PR #33 commit checks and the exact case ledger.

| Finding | Native boundary |
| --- | --- |
| Short ciphertext read replacing a destination | Streaming exact reads and atomic save preserve the original file |
| Cleanup deleting a live write | Unique PID/random temporary ownership, active registry/lock and competing-write tests |
| Pre-restart uploads mutating new state | Lifecycle generations and new-run outbound ownership |
| Early discard lost during creation | Pending request identity and early terminal reconciliation |
| Malformed restored fields | Strict typed deserialization, whole-state validation, safe chat identity context |
| Invalid forwarding key/caption | Reference fingerprint/media-kind validation before reservation |
| Invalid/trailing media reference | Complete validated file-media object and version/type checks |
| Known TL constructor in wrong family | Schema preflight checks every declared result family |
| Failed service commit changing live state | Transaction rollback and durable applied-delivery marker |
| Cancelled shutdown/returned task ownership | Shared lifecycle completion, pre-poll future ownership and redacted failures |
| AES backend evidence | Same inventory on default and forced portable AES matrix legs |

Every original parametrized scenario is mapped to a distinct Rust case. The
security suites additionally audit actual RNG AST/dataflow and typed refusal
privacy. See [native audits](../rust-security-audits.md), [case ledger](../../migration/README.md)
and [architecture](../architecture.md). No account credentials or private live
message data are part of these fixtures.
